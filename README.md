# PianoVision Pro

Apple Vision Pro 钢琴练习应用，通过 Mac 中转接收电钢琴的 USB MIDI。支持 88 键对齐、平铺音符引导、实时按键反馈、MIDI 曲库和可选指法建议；当前不支持蓝牙 MIDI。

连接方式：电钢琴 **USB COMPUTER → Mac / PianoBridge → 局域网 → Vision Pro**。应用只传 MIDI，不传音频；声音由电钢琴或其音箱、耳机输出，Mac 测试按钮不发声。

## 快速开始

需要 macOS 15+、visionOS 2+ 和包含 visionOS SDK 的 Xcode。工程使用本地 Swift Package，无第三方依赖。

1. 打开 `PianoVisionPro.xcodeproj`，选择 **PianoBridge** scheme 和 **My Mac** 运行。
2. 将 RD-2000 / RD-2000 EX 的 **USB COMPUTER（USB-B）** 接口连接到 Mac，在 PianoBridge 中选择 MIDI 输入并连接。USB MEMORY / UPDATE 接口不能用于此连接。
3. 选择 **PianoVision** scheme，在 Signing & Capabilities 中设置自己的开发团队与唯一 Bundle ID，选择已配对的 Vision Pro 运行。
4. Mac 和头显连接同一局域网，允许本地网络访问。在头显“连接”页选择 Mac；自动发现失败时，输入 Mac 的局域网 IP 和 PianoBridge 显示的端口。
5. 在 Mac 点击“测试 C 大三和弦”，确认头显上的 C4、E4、G4 能高亮并恢复。
6. 打开“空间练习”，在“琴位校准”中完成下方校准步骤。
7. 从“曲库”载入 MIDI 或内置练习曲，选择练习轨道，点击“开始练习”。应用会自动进入空间练习；空间或琴位未就绪时保持暂停并提示处理。

找不到 MIDI 输入时，先在 macOS“音频 MIDI 设置 → MIDI 工作室”检查设备与驱动。若 RD 的多个音区重复输出相同音符，可在头显“接收 MIDI 通道”中选择单一通道。

## 琴位校准

1. 点击“3 秒后采左端 A0”，将左食指轻触最左 A0 白键的**前缘中心**，不按下琴键，保持到取点完成。
2. 按同样方式，用右食指采集最右 C8 白键的前缘中心。首次使用需允许手部追踪。
3. 检查两端、C4 和黑键；需要微调时开启“显示校准参照”，用方向、角度和尺寸按钮调整，最后“保存并固定琴位”。

琴位默认锁定，不通过手势拖动。校准参照独立于练习底图，后者默认透明。指尖取点只能估算琴位，仍需检查高度和黑键。移动实体钢琴、换房间或锚点恢复失败后，应重新校准。

## 导入与查找曲目

- **头显导入**：在“曲库”点击“导入 MIDI”，选择单个 `.mid` / `.midi` 文件。
- **Mac 单首导入**：在 PianoBridge 选择 MIDI 文件、接收头显，再发送；头显保存后自动载入。
- **Mac 批量导入**：选择文件夹后递归扫描子文件夹，逐首加入曲库，不切换当前练习。可查看失败原因、取消及重试未完成项；断连后需手动重新连接和继续。

支持 MIDI Format 0/1、多轨、变速和拍号，每首最大 20 MB。曲目、收藏及练习标注保存在头显本机。

曲库支持名称搜索、仅看收藏、导入时间、名称和最近打开排序，**收藏在所有排序中置顶**。可选列表或纵向卡片，卡片每行 2–4 张。排序、布局、列数和收藏长期保存；滚动位置、搜索和收藏筛选在**当前窗口内切换页面**时保留，关闭窗口或重新启动后不恢复这些浏览状态。点击当前曲目返回练习台并保留进度。

## 练习与反馈

**弹对再继续**：到目标处等待，当前和弦可逐音弹完，已弹对的音允许松手，适合琶音和大跨度移位。提前按下后续组的音，需要保持到该组成为当前目标；后续重复音必须松开重弹。等音时只高亮当前组的目标琴键，后续音符仍显示预读。

**自动滚动**：开始、继续或播放中跳转后，先滚动实际 3 秒再开始判定。准备时间不随速度变化，期间输入不计分。目标音对齐容差在此模式中同时允许提前和滞后匹配。

“回到开头”确认后会暂停、归零并清空本轮统计，不自动播放。播放速度支持 50%–120%，每次调整 10%。轨道可指定左右手，自动拆手默认以 C4 为界；指法建议为 1–5，可手动修正，不检测实际手指。

| 显示 | 含义 |
| --- | --- |
| 蓝 / 橙 / 灰音符 | 左手 / 右手 / 未分配；黑键音符颜色更深 |
| 整键持续高亮 | 绿：正确或已就位；红：错音；青：普通按键输入。松键后恢复目标提示 |
| 空间音符提亮与绿色边线 | 对应音符正在由真实琴键按住；普通白色边线也用于强调当前目标 |
| 绿勾 | 已累计或已完成；当前组松手后保留 |
| 青色短线 | 后续目标已提前按下，仍需保持到它进入当前组 |
| 双起音线 | 同音需要松开重弹；普通起音标记关闭后仍会显示 |

练习台可展开“音符标记说明”和“评分说明”，设置页可展开评分规则。输入时间修正仅用于自动滚动模式。

音条长度表示 MIDI 按键持续时间；踏板不会延长整键持按反馈。音符间隙只影响显示，不改变原曲时值和演奏判定。

## 评分

- **完成度** = 正确音 ÷（正确音＋错音＋漏音）× 100%。它反映已判定结果，不是曲目播放进度；无结果时为 0%。等音模式在整组通过后计正确，不计等待漏音。
- **时机分**只评已弹对的音，按下与松开各占 50%；每项偏差 ≤80 ms 满分，80–500 ms 线性降低，≥500 ms 为零。通常在松键后更新，无样本时显示“—”。该分数不改变等音通过条件或目标容差。

暂停、变速或输入中断会丢弃未完成的时值测量，保留已评样本；重头开始、跳转、换曲、切换模式或练习轨道会清空本轮统计。详细时钟、长按和延迟松键规则见 [技术说明](Docs/TechnicalNotes.md#评分实现)。

## 默认设置

下表为新安装的初始值；已保存的自定义值会保留。“恢复显示默认”只恢复显示项，不重置练习判定。

| 设置 | 默认值 | 可调范围 |
| --- | --- | --- |
| 练习模式 | 弹对再继续 | 弹对再继续 / 自动滚动 |
| 目标音对齐容差 | 2 s | 50 ms–2 s，位于“设置 → 练习判定” |
| 预读时长 | 实际 5 s | 2–10 s |
| 音符轨道长度 | 150 cm | 35–200 cm |
| 空间音符厚度 | 8 mm | 2–20 mm |
| 音符 / 目标提示 / 持按整键反馈不透明度 | 各 100% | 各 0–100% |
| 黑白琴键底图不透明度 | 0% | 0–100% |
| 连续音间隙 | 3 mm | 0–10 mm |
| 起音线距琴键后缘 | 2 cm | 0–40 cm |
| 轨道离琴面高度 | 1.8 cm | 0–20 cm |
| 远端渐入 | 开启，强度 65% | 可关闭或调整强度 |
| 起音标记、黑键/C 音定位、拍线、琴键连接 | 开启 | 可分别关闭 |
| 自动拆手 / 指法建议 | 开启，C4 分界 / 关闭 | 可调整 |
| 曲库布局与排序 | 3 列卡片，最新导入优先 | 列表或 2–4 列卡片；收藏始终置顶 |

预读按实际秒数计算，轨道长度独立设置，变速不改变这两项。校准参照使用独立的 55% 不透明度，演奏时隐藏。

```sh
# 共享核心与网络测试
swift test --package-path Packages/PianoShared

```

Mac、visionOS 真机与模拟器构建命令，批量导入、校准及内存检查命令，以及代码结构说明见 [技术说明](Docs/TechnicalNotes.md#构建与验证)。新增或移动应用 Swift 文件后运行 `python3 Scripts/generate_project.py`，现有开发团队与签名设置会保留。

[开发记录](Docs/DevelopmentLog.md)保存历史验证结果。编译与本机回归不能替代真实琴键对齐、空间稳定性、无线延迟和佩戴体验验证；模拟器仅支持空间预览，不能保存真实锚点。

## 当前限制

- 不支持 MIDI Format 2、SMPTE 时间分辨率、蓝牙 MIDI、音频传输、云端或公网连接；断连后需手动重连。
- 计分只包含已选轨道且位于 88 键音域的音符；跨轨完全同音高、同起音的目标只要求一次物理按键。
- 指法与自动拆手为启发式建议，复杂和弦及跨手段落需手动判断。

官方硬件资料：[RD-2000 EX 规格](https://www.roland.com/nz/products/rd-2000_ex/specifications/)、[Roland USB 连接排查](https://support.roland.com/hc/en-us/articles/115001004103-RD-2000-Connecting-to-a-Computer)。
