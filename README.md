# PianoVision Pro MVP

原生 visionOS 混合现实钢琴练习应用，以及通过 USB MIDI 接入电钢琴的 Mac 中转程序。首版针对 Roland RD-2000 EX 的 88 键布局，不包含蓝牙 MIDI。

## 已实现

- **琴键对齐**：默认锁定，取消琴键模板的手势拖动与点击碰撞。可依次用左右食指轻触 A0/C8 白键前缘中心，经倒计时与稳定取样估算位置、朝向、高度与键宽；取点后检查 C4/黑键，再用 1 cm / 1 mm 方向按钮和角度、尺寸数值微调。校准参照独立于练习底图，ARKit WorldAnchor 保存与恢复。
- **MIDI 输入**：Mac CoreMIDI 设备枚举、输入源切换、热插拔；Bonjour 自动发现与 TCP 转发；时间戳转换、往返延迟测量、断连/设备切换清空状态；支持音符与延音踏板。
- **曲目导入**：头显本地选择，或 Mac 选择 `.mid` / `.midi` 文件、递归扫描文件夹后批量发送到指定头显；分块传输，头显解析并保存后逐首确认。支持 SMF Format 0/1、多轨、变速及拍号；本地曲库持久化、轨道选择、音域提示。
- **独立曲库**：列表与纵向多列卡片切换，卡片默认每行 3 张，可调 2–4 列；名称搜索、仅看收藏、导入时间新旧排序、名称自然顺序正反排序及最近打开；收藏始终置顶。收藏、排序与显示偏好保存在本机，列表显示时长、音符数和导入时间；当前曲目可直接返回练习台。
- **平铺音符**：音符与琴面平行，从整排琴键后缘外向前接近起音线；连续同音具有可调间隙和独立起音标记。预读按实际秒数设置，轨道长度独立可调，变速时两者保持稳定；支持远端渐入、稀疏黑键/C 音八度定位、拍线与小节线、起音线到琴键的连接。音符、模板、琴键高亮和按键反馈分别可调透明度；显示设置自动保存。
- **左右手颜色**：左手蓝色、右手橙色、未分配灰色；窗口预览与空间瀑布流、目标琴键共用配色。按轨道指定左右手，未指定的轨道可按分界音自动拆手。
- **弹对再继续**：统一使用逐音累积判定，允许按设定容差提前准备下一目标，当前组允许像琶音一样逐音累积，松手移位不丢失已弹进度。30 ms 内重叠起音合组，网络批量送达也可续接；重复音仍须松开重弹。目标音对齐容差默认 2000 ms，可在 50–2000 ms 调整。
- **指法建议**：可选生成 1–5 指法，在窗口及空间音符上显示；支持逐音修改与恢复建议，轨道演奏手和手动指法随曲目保存。
- **演奏反馈**：物理按住期间整键持续显示已就位/正确绿、错音红或普通按键青，松手恢复目标手色，每次 NoteOn 都有独立的短闪回声；瀑布音条保留左右手底色，实际按住时提亮并显示亮边，已累计或完成的音显示绿勾，提前就位的后续目标显示青色短线。反馈按音符 ID 对应，不会把后面的同音重复条一起点亮。黑键音条同手更深，白键更亮并保留清晰边界；黑白底图可单独控制。等待模式统计正确与错音；自动滚动模式另评估起音时差与漏音。新增完成度与起音/松键时机百分比评分；不评估力度质量或实际使用的手指。
- **无琴调试**：Mac 提供 C 大三和弦/音阶测试按钮；头显内置原创双手练习 MIDI，带有变速段。

## 打开与运行

需要 Xcode（含 visionOS SDK）、macOS 15+，以及运行 visionOS 2+ 的 Apple Vision Pro。工程使用本地 Swift Package，不依赖第三方包。

1. 打开 `PianoVisionPro.xcodeproj`。
2. 选择 **PianoBridge** scheme 和 **My Mac**，运行 Mac 中转程序。
3. 用 USB 数据线把琴背面的 **USB COMPUTER（USB-B）** 连接到 Mac。不要使用 USB MEMORY / UPDATE 接口。
4. 在中转程序选择 RD-2000 EX 对应的 MIDI 输入并点击“连接”。若没有设备，先在 macOS“音频 MIDI 设置 → MIDI 工作室”确认设备可见，并按照 Roland 的驱动/USB 模式说明排查。
5. 选择 **PianoVision** scheme，在 Signing & Capabilities 中选择自己的开发团队与唯一 Bundle ID，选择已配对的 Vision Pro 后运行。
6. Mac 与 Vision Pro 接入同一局域网，首次运行允许本地网络访问。在头显的“连接”页选择发现的 Mac。发现失败时可输入 Mac 的局域网 IPv4 地址和中转界面显示的端口。端口由系统分配，自动发现会一并读取端口。
7. 点击 Mac 的“测试 C 大三和弦”，先确认头显预览的 C4 / E4 / G4 高亮与松开正常。
8. 打开“空间练习”，进入“琴位校准”。可先取左右端指尖位置，或显式开启“显示校准参照”用按钮对齐。检查两端白键前缘、中部 C4、高度与黑键，再点击“保存并固定琴位”。
9. 载入示例或导入自己的 MIDI，选择练习轨道，点击“开始练习”会自动打开空间练习；空间追踪就绪后开始，自动滚动仍先预滚动 3 秒。若空间打开被取消或失败则保持暂停；琴位未就绪会提示校准。

在 Mac 导入单首曲目时，点击 PianoBridge 的“选择 MIDI 文件”，选择已连接的接收头显，再点“发送到 Vision Pro”。头显解析并保存成功后才确认导入，并载入该曲目。

批量导入时点击“选择文件夹”，会递归查找其中的 `.mid` / `.midi`（不区分扩展名大小写），跳过隐藏文件、应用包及符号链接。列表显示相对路径和逐首状态，每首最多 20 MB；只在发送当前曲目时读取其数据。点击“批量导入到 Vision Pro”后逐首发送、解析和保存，批量曲目只加入曲库，保留当前练习。单首失败会记录原因并继续；取消或断连后停止，连接后点击“继续 / 重试未完成”。同一连接重试时已确认成功的条目不会重发；重连或更换接收头显后会重新确认整批，同一头显通过持久化导入标识避免重复入库。源文件修改后需重新选择；重新选择文件夹会创建新队列。连接恢复不会自动发送。

在头显顶部打开“曲库”，或从练习台点击“打开曲库”。默认使用每行 3 张的卡片布局，可在列表与卡片间切换，并选择每行 2、3、4 张；两种布局都纵向滚动，显示方式与列数会保存。切换页面后曲库保留原来的滚动位置、搜索内容与收藏筛选，不再回到列表顶部；离开曲库会收起搜索键盘。默认按导入时间从新到旧排列；可切换名称顺序、反序、最早导入或最近打开。无论选择哪种排序，星标收藏都排在其他曲目之前；打开“只看收藏”可进一步筛选，也可输入部分曲名查找。收藏、搜索和排序不切换当前曲目；点击其他曲目才载入，点击当前曲目直接回到练习台并保留进度。旧曲库自动兼容，导入时间尽量取已存 MIDI 的文件日期，无法恢复的日期显示为未知并排在有日期曲目之后。

RD-2000 EX 的多个音区可能同时输出相同音符。出现重复输入时，选择头显“接收 MIDI 通道”中的单一通道，并检查琴的外部音区设置。

声音由电钢琴本身或其外接音箱/耳机输出；本项目只传输 MIDI 事件，不传输音频。Mac 测试按钮本身不发声。

## 练习方式与指法

“弹对再继续”统一采用逐音累积判定。音符到达目标便等待，当前组目标逐音弹完后恢复滚动。允许按“目标音对齐容差”提前按下当前或后续目标（50 ms–2 s，默认 2000 ms）：当前和弦内可以逐个弹下并松手，方便大跨度和弦以琶音方式完成，已弹目标不因松手或手间间隔而丢失。当前组弹完后按原谱面时刻继续滚动，不会提前跳过节奏。尚未轮到的后续组，提前输入仍需保持到其进入当前组，提前松开则撤销；进入当前组后采用逐音累积规则。

引擎把首起音 30 ms 内且时值重叠的音符组成和弦，不连续链式合并；跨轨/通道重叠同音只要求一个物理按键，同一轨道的后续重复起音仍独立。旧长按、重复多通道输入和踏板延音不能自动通过后面的重复音，必须松开再按。暂停、跳转、变速与输入源变化会清除未完成的按键组合；断连会暂停练习。网络送达时间不再用于丢弃下一组的有效新起音。

旧版保存的严格判定与和弦时间差参数会被忽略，新设置不再写入这两个字段；其他练习偏好保留。

“自动滚动”在开始、暂停后继续或播放中跳转时，先滚动 3 秒准备段，再从所选谱面位置开始计分。准备时间为实际 3 秒，不随播放倍率变化；准备期间只显示物理按键反馈，不计正确、错音或漏音，准备段内发生的 MIDI 起音即使晚送达也不参与之后的判定。暂停取消准备段，再次开始重新准备；切换曲目、练习模式或回到开头会清理旧准备状态。点击“回到开头”会先弹出确认，只有确认后才暂停、跳到曲首并清空本轮统计，不自动播放；取消不重置进度。自动滚动可单独调整输入时间修正；“目标音对齐容差”在自动滚动中作为提前与滞后的匹配范围，范围同为 50 ms–2 s。

在“练习轨道”里为每个轨道选择“自动 / 左手 / 右手 / 未分配”。初始分配会参考轨道名及音区；单轨 MIDI 默认以 C4 为分界，低音建议左手，分界音及以上建议右手。自动拆手只是初步建议，跨手段落需要手动判断。

打开“显示指法建议”后自动生成，1 为拇指、5 为小指。算法按手分别考虑旋律移动、和弦跨度、黑白键及持续音占用；无法可靠安排的和弦留空。使用“修正接下来的音符”选择目标，再点击 1–5 手动修改，或点“恢复建议”。手动修正不会被重新生成覆盖；改变音符的演奏手会清除该音符的旧指法修正。指法是启发式建议，不检测实际手指。

目标音对齐容差统一在“设置 → 练习判定”中调整，范围与已有保存值保持不变。“设置”中也可分别调节四类不透明度、连续音间隙、起音线与琴键后缘的距离，以及轨道离琴面的高度。预读默认 5 秒实际时间（可调 2–10 秒），轨道默认长 1.5 m（可调 0.35–2 m）；播放倍率只改变谱面时间换算，不再单独设置音符前进速度。远端最后 20% 逐渐显现，可关闭或调整强度。默认起音线在后缘外 2 cm，连续音至少留出 3 mm 视觉间隙。间隙只裁剪显示尾端，不改变 MIDI 时值和判定；白色起音短线表示一次新的按键。

按住整键反馈、目标提示和音符默认不透明度均为 100%，练习黑白底图为 0%。display/practice 设置带版本：旧默认透明度和旧 800 ms 对齐容差会一次升级到新默认，自定义值保留；升级后手动选回旧值也会保存，不会在下次启动被重复覆盖。校准参照固定使用独立的 55% 不透明度，开始演奏时隐藏，不受练习底图为 0% 影响。反馈依照实际物理按键持续到最后一个同音通道松开，踏板不延长整键按住状态。白键高亮覆盖可见的整段键面并避开黑键占位，黑键沿自身顶面显示，保持校准尺寸。瀑布音条默认厚度为 8 mm，可在“设置 → 空间音符厚度”调节 2–20 mm；音条底面、长度和 MIDI 时值保持不变，起音标记与指法随顶面上移。

音条的左右手颜色在命中后保留；亮边表示对应音符仍由真实按键按住，绿勾表示已经累计/完成。提前弹下的后续目标用青色短线提示仍需保持到它进入当前组；当前组松手移位则保留绿勾。等音模式只高亮当前组尚未弹完的目标琴键，当前组全部通过后才切到下一组；后续音条继续保留瀑布流预读，不再提前浅亮后续琴键或连接。未完成目标有更清楚的音头与边缘；当前组提示按实际容差秒数和播放倍率换算，自动模式保持原有节奏计分与预告。旧长按占住后续重复音时，双起音短线提示需松开重弹；关闭普通起音标记后仍保留这类重弹提醒。每次物理 NoteOn 的前缘回声保留 180 ms（先短暂保持，再淡出），不延迟实际持按反馈。

音条长度表示 MIDI 时值，不再显示额外的长音余量尺、黄色松键提示或对应设置项。黑键分组/C 音八度定位、拍线与小节线及连接提示均可独立关闭。拍线按 MIDI 变速和拍号生成，缺少相关信息时使用 MIDI 默认的 120 BPM、4/4；拍号中途改变从新小节起算。窗口预览与空间练习使用同一时间、目标和高亮语义。

## 练习评分

演奏反馈显示两个独立百分比：

- **完成度**：正确音数 ÷（正确音数＋错音数＋漏音数）× 100%，随已判定结果更新，尚无结果时显示 0%。等音模式沿用和弦累计完成后计正确、不计等待漏音的规则。
- **时机分**：仅对已弹对的音评分，每音按下与松开各占 50%；真实时间偏差在 80 ms 内为满分，在 80–500 ms 间线性降低，达到 500 ms 为零。按下后等待真实松键再更新样本，尚无样本显示“—”。零时值音只评起音。一直不松键超过谱面结束 500 ms，松键项暂计零分；若之后收到时间戳正确的延迟松键，修正原样本而非重复加分。

时机分使用接收端时钟域中的 MIDI 源事件时间，并换算播放倍率。等音模式按每组原定到达时间评起音，避免冻结的谱面时钟掩盖晚弹；长音按原谱时值换算真实松键时刻。踏板不延迟物理松键评分，多通道同音以最后一个物理通道松开为准；重复 NoteOn 不重复计分或判错。当前组琶音样本在整组通过时提交，提前松开的后续候选被撤销时不计入；同音别名只计一次。时机分只提供反馈，不改变按键接受范围、等音累计或通过条件。

暂停、变速、修正输入时间及输入源重置会丢弃尚未完成的时值测量，保留已评样本；重头开始、跳转、换曲、切换模式或练习轨道会与本轮统计一同清空。

## 校准说明

位置初值位于当前空间原点前方约 65 cm、高度约 72 cm。校准参照默认关闭，只有显式开启或开始取点时进入校准；恢复已保存设置也默认锁定。键盘横向以完整键盘的中点为中心，默认 52 个白键，每个宽 23.5 mm。尺寸是可调初值，需要按实际琴键对齐。

未固定时，位置参数相对于当前空间坐标；固定后参数归零，成为相对于已保存琴位的微调。尺寸与微调持久化到本机。WorldAnchor 固定在房间中，不跟随被移动的琴，也不能保证跨房间恢复。恢复失败时点击“重新放置琴位”再校准。

指尖校准采用顺序两端取点：点击“3 秒后采左端 A0”，把左手食指轻放在该白键前缘中心，不按下琴键，等待稳定采样成功；再以右手食指取最右 C8 的同一位置。每次需至少 8 个新样本、连续约 0.4 秒，抖动不超过 6 mm；明确失追踪会重新累计，单端超过 10 秒可重试。左端超过 2 分钟或空间追踪丢失需重采。每步只读取当前指定食指，采样结束移除手部 provider；中断时在空间追踪恢复后完成清理。

两端中心间距按 51 个白键间隔计算，估计位置、键宽、水平朝向和横向倾斜；两点不能推断前后俯仰与琴键深度，初始按水平琴面处理，键深保留原设置。关节位置不等同精确指腹接触点，因此完成后仍要检查高度、C4 和黑键，必要时用按钮微调，再显式保存。取点未完成前不改变原琴位；取消、离页、追踪中断和旧异步任务不能提交过期结果。取点期间不允许播放或保存半套位置。

手势拖动入口已取消，所有校准参照都不接收抓取或点击。粗调为 1 cm、细调为 1 mm，角度和尺寸也支持相应粗细步长；未显式显示参照时位置与尺寸控件锁定，保存中禁止冲突操作。

指尖取点使用普通 ARKit HandTrackingProvider，仅在显式点击取点后请求手部追踪权限并读取指尖世界坐标。不读取原始相机，不使用企业 API，也不把注视实体琴键加捏合当成真实三维测量。“把模板放到面前”仍只提供手动校准起点。两端触键加微调的交互参考 [PianoVision 官方校准说明](https://www.pianovision.com/resources/)。

## 首版范围

- MIDI Format 2 和 SMPTE 时间分辨率会返回明确错误。支持的文件最大 20 MB。
- 乐谱中的延音踏板不改变瀑布流音符长度；长度表示 MIDI 按键持续时间。实时踏板与物理按键状态分开处理。
- 演奏计分只包含已选轨道、88 键音域内的音符；不同轨道完全同音高、同起音的重叠目标按一次物理按键处理。
- 首版连接为局域网 TCP，未接入云端，也未实现跨公网连接、自动重连或 BLE MIDI。断连后重新选择 Mac 连接。
